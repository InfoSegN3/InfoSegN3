# 📅 Agendamento WEB (Agenda Acadêmica)

## 🎯 Objetivo do Projeto
Este sistema foi desenvolvido como requisito para a **Avaliação N3 da disciplina de Segurança da Informação**.

O projeto segue o tema oficial **P02-A (Agendamento Acadêmico)** e tem como objetivo centralizar o atendimento entre alunos, professores e secretarias em uma plataforma confiável.

Mais do que um sistema funcional de agendamento, a aplicação foi construída com foco na aplicação prática de controles de segurança da informação, implementando na base do código:

- **Autenticação e Autorização:** Controle de Acesso Baseado em Papéis (RBAC) com segregação clara entre Alunos, Recepção/Professores e Administradores.
- **Trilha de Auditoria:** Registro rigoroso de eventos e ações sensíveis no sistema.
- **Proteção de Dados:** Uso de hashes para senhas e validações rigorosas no servidor (back-end).

## 💻 Stack Tecnológica
A aplicação foi construída adotando uma arquitetura simples e direta, sem o uso de frameworks pesados no front-end, focando na solidez do back-end:

* **Front-end:** HTML, CSS e JavaScript.
* **Back-end:** PHP.
* **Banco de Dados:** MySQL.
